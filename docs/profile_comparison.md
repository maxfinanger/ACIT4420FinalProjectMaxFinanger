## How to read this

- The ranking is a recommendation under the hard constraints, the profile weights and the scoring assumptions in `docs/scoring.md`. It is not an absolute truth about which bus is best.
- The profile weights are invented for this project, not measured from real travellers.
- Price and duration are scored relative to the offers that passed the filter (`docs/scoring.md`, D15), so the scores only have meaning within this request.
- Reproduce a single profile with `python main.py --destination Malaga --from 2026-07-12 --to 2026-07-14 --budget 50 --max-transfers 1 --changeable --profile <name>`, or all at once with `--compare-profiles`.
