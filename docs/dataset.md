# Dataset description

All data is fictional. It is generated by `scripts/generate_data.py` with a fixed
seed (42), so running the script again gives exactly the same files. A test
(`test_committed_file_matches_generator_output`) checks that `data/offers.csv` still
matches the script.

```bash
python scripts/generate_data.py
```

## Files

| File | Content |
|---|---|
| `data/companies.csv` | the 5 companies and their profile text |
| `data/destinations.csv` | the 15 destinations |
| `data/offers.csv` | 1497 valid offers, 75 company-destination combinations |
| `data/offers_invalid.csv` | 20 rows for testing validation (17 broken, 3 valid boundary cases) |
| `data/offers_invalid_expected.json` | for each row of the invalid file, what it should be detected as |

## Offer fields

`offer_id, company, destination, travel_date, departure_time, arrival_date,
arrival_time, fare_type, price, transfers, luggage_kg, changeable, refundable,
seats_available, rating, emissions_kg`

- `arrival_date` is separate so overnight journeys are possible (decision D11).
- `fare_type` is Basic, Standard or Flex, and decides price, changeability,
  refundability and luggage (decision D12).
- `rating` is per company and destination (same for all its departures on a route).
- `emissions_kg` is an optional environmental measure (CO2 per passenger).

## How the companies differ (the decisions behind the data)

| Company | Price level | Speed | Departures | Transfers | Fare types |
|---|---|---|---|---|---|
| SolRuta | lowest (x0.80) | slow (65 km/h) | 2 per day on every route, daytime only | often on long routes | Basic (not changeable), Standard |
| Camino Express | highest (x1.20) | fast (85 km/h) | 3 per day to six major cities, 1 per day elsewhere | direct to major cities, 1 transfer elsewhere | Standard, Flex (changeable and refundable) |
| CostaLink | medium (x0.95) | medium (72 km/h) | 3 per day to coastal destinations, 1 inland | direct on the coast, 1-2 inland | Basic, Standard, Flex |
| VerdeBus | above average (x1.10) | medium (75 km/h) | 2 per day | mostly direct | Standard, Flex; emissions about 30% lower |
| NocheVia | low (x0.90) | medium (78 km/h) | 2 per day between 21:00 and 00:45 | sometimes | Basic, Standard |

Price per trip = (EUR 5 + EUR 0.055 per km) x company factor x fare factor, minus
3% per transfer, plus 8% on Friday-Sunday, with +/-5% random variation, rounded to
EUR 0.50. Duration = distance / speed + 15 min + 35 min per transfer (+/-5%).
Fare factors: Basic x0.90-1.00, Standard x1.12-1.18, Flex x1.25-1.35, depending on company.
Each fare type has its own seat count (a quota per fare type).

Dates: 11-15 July 2026 (the example request in the spec uses 12-14 July).
Distances from Madrid are approximate road distances.

Other numbers: 286 of the 1497 offers are overnight (arrive the next day), prices go
from EUR 6.50 to EUR 69.00 (median EUR 32.00), and 163 offers have 4 seats or fewer.

For the example request in the spec (Madrid to Malaga, 12-14 July, max EUR 50,
at most 1 transfer, changeable ticket required), 47 offers from all five companies
remain, so the ranking has real choices to compare.

## Invalid test file

`offers_invalid.csv` has one row for each type of error that the spec mentions, plus a few
more, and two valid boundary rows that must **not** be rejected (an overnight
journey, and the lowest allowed rating and seat count). The expected result for each
row is in `offers_invalid_expected.json`, so the Phase 3 tests can check the validation
against it automatically. Error categories used:
`negative_price, unknown_destination, unknown_company, invalid_date,
arrival_before_departure, rating_out_of_range, no_seats, missing_field,
invalid_number, bad_offer_id, invalid_time, negative_transfers, invalid_boolean,
duplicate_id, malformed_row, impossible_duration`.

## Known limitations of the data

- Everything is synthetic, so prices and times say nothing about real operators.
- Ratings are one number per company and route, not a real review distribution.
- All routes start in Madrid, and all dates are within five days.
- Every route has the same schedule each day (a few random cancellations aside).
